# MyTers 下载中心

独立产品下载页面，使用静态 HTML、CSS 和 JavaScript，无需构建工具。

- 仓库根目录：V1.0。
- `s1.0/`：S1.0，包含独立页面及资源。

## 本地预览

在仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/` 查看 V1.0，访问 `http://localhost:8000/s1.0/` 查看 S1.0。

## 内容维护

页面的链接与版本号位于各版本的 `index.html`。修改移动端下载地址时，请同时更新对应二维码。约课和在线客服目前为待接入提示。Mac 设备卡片包含 Apple 和 Intel 两种芯片下载入口。
