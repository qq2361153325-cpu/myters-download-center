# MyTers 下载中心 V1.0

MyTers 产品下载页面，静态 HTML、CSS 和 JavaScript，无需构建工具。

## 本地预览

在此目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。

## 内容维护

- 页面结构、样式、下载链接和版本号位于 `index.html`。
- `assets/` 包含产品展示图、标识和移动端下载二维码。修改移动端链接时，应同时更新对应二维码。
- 约课和在线客服当前为待接入提示，需要提供实际链接后接入。
- Mac 设备卡片包含 Apple 和 Intel 两种芯片下载入口。
